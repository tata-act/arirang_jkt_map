Cara estimasi

  • Nomor kursi diperlakukan sebagai kolom yang sejajar di satu sisi. Row depan lebih pendek karena terpotong lengan stage, jadi nomor awalnya besar (row A VIP A/C = 54–123).
  • Min/maks tiap row diambil dari laporan sensus terjauh dari tengah, dibuat simetris (tengah A/C = seat 88,5, B/D = 71,5). Row belakang tidak boleh lebih sempit dari row di depannya.
  • Pola ini cocok dengan data blok BTS Arirang Bangkok: sisi panjang melebar 3 kursi/row di tepi lengan, dan blok sudut di belakang platform baru mulai di row J (sisi A/C) dan row N (sisi B/D). Di Jakarta, A/C juga melonjak di row J, B/D di row N dan Z.
  • Row tanpa data, atau dengan data yang lebih sempit, ikut row di depannya. Row depan B/D yang datanya tipis (A–C) ikut row D.
  • VIP A dan C dihitung bersama (cermin), begitu juga B dan D. Hasilnya identik untuk pasangannya.
  • 2* dibaca 20–29, 1** 100–199. Nilai bertanda bintang hanya dipakai sebagai batas aman.

Asumsi yang belum pasti

  • Row A paling dekat stage, seat 1 paling kiri. Untuk B/D, seat 1 digambar di atas.
  • Orientasi mengikuti peta tiket Jakarta: A atas, C bawah, B kanan, D kiri. Ini sama dengan peta Bangkok yang diputar 90° (V7–V11 → A, V3/V15 → C, V12–V14 → D, V4–V6 → B).
  • Platform catwalk digambar di titik row melebar (A/C row J, B/D row N dan Z), lebarnya mengisi celah kosong di antara kursi. Posisi persisnya belum dikonfirmasi.
  • Platinum A/C: sayap kiri-kanan VIP mulai row P (laporan 163–173 di row P), lalu row penuh V–AB selebar row U (1–176).
  • Platinum B/D: sayap AH–AJ hanya didukung laporan D-AH 12, jadi masih dugaan. Row penuh AK–AZ.
  • Row terakhir Platinum (AB dan AZ) adalah row terakhir yang dilaporkan, belum tentu row terakhir sebenarnya.
